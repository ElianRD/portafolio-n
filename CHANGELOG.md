# Estado actual
El sitio web es una Single Page Application construida con Vue 3 y Vite. Funciona como un portafolio personal navegable que incluye secciones de Inicio, Sobre mí, Proyectos y Contacto. La interfaz utiliza SCSS para el diseño responsivo, Swiper para el carrusel de proyectos, e íconos de Boxicons. La arquitectura está dividida en vistas (views), componentes (components), y un diseño central (MainLayout).
